### 3.2 Nginx + HTTPS

`nginx/mcd-soulmate.conf`（模板，域名用占位符）：
- `web/` 作为 `root`，静态托管
- `/api` → `proxy_pass http://127.0.0.1:3000`
- **SSE 关键配置（必须，否则流式回复会卡住）**：
  ```nginx
  proxy_buffering off;
  proxy_cache off;
  proxy_read_timeout 120s;
  proxy_http_version 1.1;
  proxy_set_header Connection '';
  ```
- HSTS、`X-Content-Type-Options`、`X-Frame-Options`、基础 CSP
- gzip 静态资源（不要 gzip SSE）
- 静态资源 `expires`，`index.html` 不缓存（避免更新后用户看到旧版）

HTTPS：`certbot --nginx -d your-domain.com`，写进 README。

### 3.3 pm2 + 进程守护

`server/ecosystem.config.js`：
- `name: 'mcd-soulmate'`、`script: 'dist/index.js'`
- `instances: 1`（SQLite + 内存连接池，**不能 cluster 多实例**，会互相踩）
- `max_memory_restart: '500M'`
- `env: { NODE_ENV: 'production' }`
- 日志输出到 `logs/`，配 `pm2-logrotate`（可选，说明一下即可）

启动脚本 `scripts/deploy.sh`（幂等，可重复执行）：
```bash
git pull
cd server && npm ci && npm run build
pm2 reload ecosystem.config.js --update-env
```
加上 `set -e`、关键步骤 echo、失败即退出。

```bash

**注意 crontab 里 `%` 要转义**（这是常见踩坑点，README 里说明）。
