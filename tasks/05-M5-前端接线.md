**SSE 消费（重点）**：
```js
const res = await fetch('/api/chat', { method:'POST', headers:{...}, body: JSON.stringify({message}) });
const reader = res.body.getReader();
// 手动解析 event: xxx\ndata: {...}\n\n 格式
```
- 收到 `stage` → 在聊天流末尾显示一个"进度气泡"，文案来自 `event.text`，带 demo 的 `.typing` 三点动画
