### 3.4 Token 登录全链路（核心）

`POST /api/auth/login`，请求 `{ token: string }`：

1. 校验 token 非空、长度合理（<20 字符直接 400）
2. **验证真实性**：调用 MCP 工具 `now-time-info`，带上 `Authorization: Bearer <token>`
   - 实现方式：用 `@modelcontextprotocol/sdk` 的 `StreamableHTTPClientTransport` 建一次性连接，
     `requestInit.headers` 注入 Authorization，调 `now-time-info`，成功后关闭连接
   - 401/403 → 返回 `401 { error:"TOKEN_INVALID", message:"这个 Token 失效了，去 open.mcd.cn 重新生成一个" }`
   - 网络错误/超时（10s）→ 返回 `503 { error:"MCP_DOWN", retriable:true }`
   - **注意**：这个验证函数单独放在 `services/mcp-verify.ts`，M3 会把完整网关做出来，届时可能复用它
3. 派生身份：`user_id = sha256(token).slice(0, 16)`（小写 hex）
4. 加密 token：AES-256-GCM，格式 `base64(iv(12B) || authTag(16B) || ciphertext)`，
   密钥从 `TOKEN_ENC_KEY` 解 hex。实现放 `lib/crypto.ts`，要能往返解密验证
5. Upsert `users` 表：已存在则更新 `token_enc` + `updated_at`，不存在则插入
6. 签发 JWT（`{ sub: user_id }`，7 天过期），写入 httpOnly Cookie：
   - `httpOnly: true`, `sameSite: 'lax'`, `secure: NODE_ENV==='production'`, `maxAge: 7d`, `path: '/'`
7. 返回 `{ ok: true, userId, isNew, needOnboarding }`
   - `isNew` = 本次是插入（不是更新）
   - `needOnboarding` = `users.nickname IS NULL`

另外三个接口：
- `POST /api/auth/logout` → 清 Cookie，返回 `{ ok: true }`（不解绑）
- `DELETE /api/auth/unbind` → 删除该用户的 `users` / `memories` / `mood_diary` / `orders` / `chats` 全部数据，清 Cookie
- `GET /api/me` → `{ userId, profile?: {nickname,birthday,starSign,taboo}, hasToken: true, needOnboarding }`

### 3.5 中间件
- `middleware/jwt.ts`：校验 Cookie 里的 JWT，挂 `req.userId`；失败返回 401。
  **除 `/api/auth/*` 和 `/api/health` 外全部挂载**
- `middleware/ratelimit.ts`：内存 token bucket，`/api` 全局 IP 30 req/min；实现简单够用即可，
  用 Map + 定时清理，不用引第三方库
- 统一错误处理器：捕获 throw → 输出 `{ error, message, retriable? }`，
  **且必须脱敏**：日志里 token 只显示前4后4位

### 3.6 日志脱敏（重点，别漏）
`lib/logger.ts`：包装 console，提供 `info/warn/error`。所有日志在输出前过一遍 `sanitize()`：
- 识别 `Bearer xxx`、`"token":"xxx"`、64 位以上 hex/base64 长串 → 替换为 `abcd****wxyz`
- 确保 error 堆栈里也不泄露
