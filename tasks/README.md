## 三个会话级的硬规矩（每个提示词里都重申了）

1. **契约冻结后不许单方面改**。要改接口/字段，先在 `server/src/types/contract.ts` 和 `docs/contract.md` 里加，再通知我。
2. **禁止编造菜单、价格、优惠券**。生产代码里的所有商品数据只能来自 MCP；mock 数据必须打 `MOCK` 标记且只在开发期使用。
3. **禁止任何真实 Token / 密钥进仓库**。`.env` 只留在本地，`.gitignore` 必须生效。
